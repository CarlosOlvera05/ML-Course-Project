Introduction

The Problem We Are Trying to Solve

Our goal is to predict whether a video game will be a high-selling title based on information about the game.

Dataset

  • Source: Video Game Sales on Kaggle, https://www.kaggle.com/datasets/yasrebi/video-game-sales (file VideoGameAnalysis-2024.csv).
  • The file has 64,016 rows and 14 columns. One row is usually one game on one console, so a title released on several consoles has several rows. The file has 39,798 different titles.
  • The sales columns (total_sales, na_sales, jp_sales, pal_sales, other_sales) are in millions of copies.
  • Release dates in the file range from 1971 to 2024.
  • After cleaning, the models use 4,123 rows with 2,873 different titles, released from 1989 to 2020.

Prediction Task: Classification

We define a high-selling game as one game on one console (one row) that sells at least 1 million copies globally. Sales of the same title on other consoles are not added together.

Target:

  • 1 = High-Selling (≥ 1 million copies)
  • 0 = Not High-Selling (< 1 million copies)

We will compare Decision Tree, K-Nearest Neighbors and Random Forest classifiers.

Notebook Outline

  • Part 1: Initial Data Exploration – the raw file, missing values and category counts.
  • Part 2: Data Cleaning and Exploration of the Clean Data – the label, removed columns, duplicates, the complete-case filter and an exploration of the clean data.
  • Part 3: Feature Engineering – release month, release year and holiday_release.
  • Part 4: Modeling – train/test split, publisher grouping and one-hot encoding, a majority-class baseline, then tuning of a Decision Tree, KNN and a Random Forest with 5-fold cross-validation.
  • Part 5: Results & Analysis – comparison with the baseline, confusion matrices, feature importance, error analysis and limitations.
  • Part 6: Conclusion

Parts 1-3 are the assignment's "Data Exploration & Preprocessing" section, Part 4 is "Modeling", and Part 5 is "Results & Analysis".
